# Otto Smart Home Security & Voice Assistant

This repository contains the university FYP source for a Python/OpenCV/PySide6 desktop security dashboard, FastAPI backend, and Flutter mobile client.

## Scope

The project is an academic prototype. Face recognition, camera processing, diagnostic FaceOcc output, and any future presentation-attack detection must not be treated as a guarantee of identity, liveness, or physical security.

## Before running

1. Read `docs/INSTALLATION.md`.
2. Create a local environment and copy the example environment template.
3. Provide credentials only through an untracked local environment file or approved secret store.
4. Obtain third-party model artifacts directly from their authoritative sources and review `docs/MODEL_LICENSES.md`.

No credentials, customer data, webcam captures, face embeddings, or restricted model artifacts belong in Git.
